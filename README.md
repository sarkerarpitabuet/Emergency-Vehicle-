# Emergency-Vehicle
Emergency Vehicle Preemption (EVP) Using SUMO and Python TraCI
This project demonstrates how to implement emergency vehicle signal preemption using SUMO, Python, and TraCI. It covers road network creation in SUMO NetEdit, traffic signal configuration, and the addition of an ambulance and regular traffic.

The main focus is developing a Python-based traffic signal control system that detects an approaching emergency vehicle, identifies the next intersection, and adjusts signal phases to provide a green light along its route. It also explains how to monitor vehicle positions and traffic signal states using TraCI, allowing the ambulance to pass through intersections with minimal delay.
